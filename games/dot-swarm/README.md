# Dot Swarm

An OpenAI DevDay themed neon Tokyo arena game for Game Boy Color on ModRetro Chromatic. Steer a cyan
chain of Codex dots, eat gold sparks, and cut off three computer rivals.
Reach 48 dots to win. Rivals drop edible trails when they crash and can respawn.
The camera follows you around a 40 by 32 tile arena.

## Controls

- D-pad: steer in eight directions. Direct reversal is blocked.
- Hold A: double movement speed while longer than six dots. Boosting sheds mass.
- Start: pause or resume.
- Select: toggle sound.
- At the results screen: A or Start retries; B returns to the title.

Your own trail is safe. Hitting a rival or the arena wall ends the run.
This is a solo game with AI opponents. It has no networking or persistent saves.
Movement is on an eight-pixel grid, adapted to the handheld display.

## Build and verification

Run `make`, `make test`, and `make release` from this directory. Uses the existing
GBDK toolchain at `../../.tools/gbdk` and PyBoy at `../../.tools/venv`.
Editable pixel art is generated by `tools/assets.py`; gameplay is in `src/main.c`.
The game uses its own copy of the collection runtime for the DevDay title screen,
with cyan and hot-pink lettering, a window-lit skyline, animated sparks,
pulsing trails, directional eyes, and electric-green boost colors. The other
six ROMs are unchanged.

PyBoy checks cover food and growth, boost mass cost and minimum length, pause,
resume, wall and rival collision, retry, victory, rival elimination, and the
GBC header checksum. Controlled scenarios use emulator memory to arrange the
arena, followed by actual emulated game execution. Ordinary directional-input
play is also exercised. Evidence is written to `build/validation.json` and PNGs.

The standalone release is `dist/dot-swarm.gbc`, a 32 KiB GBC-only cartridge.
No physical cartridge has been written or tested for this release. The plugin's
GB Studio browser-preview route cannot preview this standalone C project.
