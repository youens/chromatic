# Dotwing

Your dot. Your sky. A fast vertical flying shooter for Game Boy Color and
ModRetro Chromatic, written in C with GBDK 4.5.0. The browser player runs the
same cartridge. One cartridge, many games.

Build a DevDay-inspired co-pilot, board your plane, and fly four sectors to
take on Grok, Claude, Gemini and Muse. Rival emblems become drones and large
boss craft: an orbital slash, coral sunburst, blue four-point star, and purple
M. These are original pixel interpretations. Muse's M is a placeholder until
the intended lab/logo is identified. This is an independent fan game with
offline arcade opponents; it does not make AI requests.

## Play

On your first launch, A or Start opens the dot builder. Use Up/Down to choose
shape, color, face or gear and Left/Right to change it. A or Start confirms
and saves; B cancels your edits. The chosen dot appears in the plane's cockpit
and colors its livery.

In the hangar, Up/Down selects wing gun, shield or reactor. A buys an upgrade
with earned tokens. Each has three permanent levels, costing 40, 80 and 140
tokens. B reopens the builder; Start launches the plane.

| Button | In flight |
| --- | --- |
| D-pad | Steer, including diagonals |
| Hold A | Precision movement; guns fire automatically |
| B | Token burst: spends 50 charge, clears hostile shots and damages rivals |
| Start | Pause; Start resumes, B banks tokens and ends the sortie |
| Select | Toggle sound |
| Start + Select | Return to the launcher in the collection cartridge |

Defeated rivals drop tokens, temporary weapon power, hull repairs and token
boosts. Boosts give rapid fire and refill burst charge. Chain defeats for
larger scores. The reactor speeds burst recharge and attracts nearby pickups;
wing guns improve damage, rate and spread; shields add maximum hull points.

Each sector has waves followed by a boss with a distinct shot pattern. After
the first three bosses, the sky station banks your tokens and offers upgrades
before the next sector. Defeat the fourth boss to earn AI supremacy. Failed
sorties keep collected tokens so another flight can start stronger.

## Saves

The ROM uses MBC5 with battery-backed 8 KiB cartridge RAM. Avatar, upgrade
levels, tokens, cleared sectors and best score use two alternating 32-byte
checksummed records at SRAM A200/A220. A record is committed last so an
incomplete write can fall back to its predecessor. This area is separate from
the collection's launcher records.

The browser saves cartridge RAM to local storage separately for each game;
the anthology keeps its own save. Clearing site storage removes that browser
save. The standalone and anthology save files are independent. A physical
cartridge needs compatible battery-backed RAM for persistence.

## Build

```sh
make -C games/dotwing all
make -C games/dotwing test
make -C games/dotwing release
make -C games/arcade release
make -C collection build
```

Run from the repository root with GBDK installed at `.tools/gbdk` and the
pinned PyBoy/Pillow dependencies in `.tools/venv`. `GBDK_HOME` and `PYTHON`
can override the standalone tool paths. Editable native pixels and cover art
are generated by `tools/assets.py`; `src/art.c` is its reproducible C export.
The standalone cartridge is `dist/dotwing.gbc` (128 KiB, GBC-only).

Gameplay is split into banked C modules; a 73-byte bridge safely passes text
between cartridge banks. Hardware background scrolling leaves the bottom two
rows for the HUD. Logic targets one update per display frame, with bounded
enemy, bullet, pickup and effect pools and 8x16 hardware sprites.

Emulator verification records the exact ROM hash, real input flows and
controlled collision/save scenarios in `build/validation.json`. Emulator
checks do not establish physical cartridge behavior or audible sound quality.
